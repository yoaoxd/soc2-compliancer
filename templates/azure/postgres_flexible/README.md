# postgres_flexible

SOC2-compliant Azure Database for PostgreSQL (flexible server): private networking
(CC6.6), TLS enforcement, zone-redundant HA (A1.1), geo-redundant automated
backups (A1.2), deletion protection (A1.3) and optional CMEK via Key Vault
(CC6.7/C1.1).

Requires the `azurerm` provider. See `variables.tf`.
